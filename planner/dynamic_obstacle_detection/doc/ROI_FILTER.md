# ROI (感兴趣区域) 过滤功能说明

## 功能概述

ROI（Region of Interest，感兴趣区域）过滤功能允许你在世界坐标系下定义一个立方体区域，只处理该区域内的点云，忽略其他区域的点云。这对于排除不感兴趣区域的干扰非常有用。

## 使用场景

1. **固定飞行区域**: 当无人机在特定区域内飞行时，可以忽略区域外的点云
2. **排除地面**: 通过设置合适的z_min值，可以过滤掉地面点云
3. **排除障碍物**: 排除已知的静态障碍物区域
4. **提高性能**: 减少需要处理的点云数量，提高处理速度

## 参数配置

在配置文件 `config/obstacle_detection.yaml` 中：

```yaml
# ROI参数（世界坐标系）
use_roi_filter: true              # 是否启用ROI过滤
roi_min: [5.0, -5.0, 0.8]        # ROI最小顶点 [x_min, y_min, z_min]
roi_max: [45.0, 5.0, 3.0]        # ROI最大顶点 [x_max, y_max, z_max]
```

### 参数说明

1. **use_roi_filter** (bool)
   - `true`: 启用ROI过滤，只处理ROI区域内的点云
   - `false`: 禁用ROI过滤，处理所有点云（默认值）

2. **roi_min** (vector<double>)
   - ROI立方体的最小顶点坐标
   - 格式: `[x_min, y_min, z_min]`
   - 单位: 米
   - 默认值: `[5.0, -5.0, 0.8]`

3. **roi_max** (vector<double>)
   - ROI立方体的最大顶点坐标
   - 格式: `[x_max, y_max, z_max]`
   - 单位: 米
   - 默认值: `[45.0, 5.0, 3.0]`

## 工作原理

### 处理流程

```
输入点云 (世界坐标系)
    ↓
ROI过滤 (如果启用)
    ↓ (只保留ROI内的点)
转换到无人机体坐标系
    ↓
FOV过滤 (视野内过滤)
    ↓
体素滤波
    ↓
统计滤波
    ↓
障碍物聚合
    ↓
转换回世界坐标系
    ↓
发布障碍物点云
```

### ROI过滤逻辑

对于点云中的每个点 `(x, y, z)`，只有同时满足以下条件时才会被保留：

```cpp
x_min ≤ x ≤ x_max
y_min ≤ y ≤ y_max
z_min ≤ z ≤ z_max
```
